# Book Exchange Platform - Frontend Deployment

This is the frontend application for the Book Exchange Platform built with React and Vite.

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

Runs on http://localhost:5173

## Build

```bash
npm run build
```

## Technology Stack

- **React 18** - UI library
- **Vite** - Build tool
- **React Router** - Client-side routing
- **Axios** - HTTP client
- **Socket.io Client** - Real-time messaging
- **Tailwind CSS** - Styling
- **Lucide Icons** - Icon library
